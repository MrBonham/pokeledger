PokéLedger

TCG Set Tracker
Data: 174 official sets from the Pokémon TCG API (snapshot, ). Your progress is saved only in this browser's local storage — it isn't shared with other viewers of this page and won't follow you to a different device or browser. Use Export/Import to back up or move it.

Tap Track on a set to follow it closely and load its full card checklist — card data loads on demand per set rather than all at once, so it needs a network connection the first time you open any given set (it's cached for offline use after that).

Want to compare with others? There's no shared server here, so each person exports their own progress from My Collection, sends the file over, and everyone loads the group's files into the Compare tab on their own copy of this page.

Master set and collection values use TCGplayer market prices, refreshed automatically once a day — treat them as a daily snapshot, not a live quote.
